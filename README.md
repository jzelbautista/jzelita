# Jzel Personal Portfolio

A responsive personal portfolio website made with HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in your browser. Keep the `assets` folder beside it so the profile photo loads.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and the `assets` folder (including `jzel-portrait.jpg`).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish your site.

## Personalize
- Replace `assets/jzel-portrait.jpg` with another photo using the same filename.
- In `index.html`, find `const recipient = '';` and add your email address between the quotes to activate the contact form.
- Update any biography details or social links as you wish.

The contact form uses the visitor's default email app; it does not store or send messages on a server.
